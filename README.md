# 年表

歴史上の出来事の関係をたどる、縦スクロールの年表アプリ。iPhoneのホーム画面から使う自分用のPWA。

公開先: https://tadamasa.github.io/history-chart/

- 年月日と出来事を入れると、時間軸の印から**引き出し線**が伸び、**カテゴリ別のレーン**にカードが置かれる(デザイン案 1b/2a: レーン型・線形軸)。
- 期間を持つ出来事は、レーンの左に縦の帯で示す。
- カテゴリは表示/非表示、追加・名前と記号の変更・並べ替え・削除ができる(最大8件)。
- 出来事を選ぶと関係のある出来事だけが残り、**AI(Gemini)で関係を紐解く**と、原因・影響・並行の関係線(破線)と解説、未登録の関連出来事の提案が加わる。2つを選んで**比較チャット**もできる。
- iPad横向き(幅900px以上)では、シートが右パネルになり、年表は残りの幅で並べ直す。
- ヘッダーの虫めがねで出来事を検索できる(題名・詳細・備考・出典・カテゴリ・年。語のAND、かな/全半角は区別しない)。iPadのキーボードでは `/` か ⌘F。
- ズームは連続。＋−は2倍ずつを0.32秒で補間(縮尺は対数、中心の年は線形)、ピンチは指の間隔の比をそのまま縮尺にし、始めたときに指の中点にあった年を中点に保つ。視差を減らす設定では補間しない。
- 「表示幅を合わせる」ボタン(＋−の下、詳細シートの右上、検索結果の見出し)。比較中はその2つ、選択中はその出来事と関係先、検索中は当たった出来事、何もなければ表示中の全部が収まる幅にする。同じ頃の出来事がレーンに積まれる分も実際の配置で見て詰める(`core.refineFit`)。iPhoneでシートが開いていればシートより上に収める。

デザインの出典: Claude Design で作ったハンドオフ(縦型年表アプリ・科学技術史、Industry デザインシステム)。

## 構成(費用0円)

ビルドなしの ES Modules を GitHub Pages で配信。データの正本は端末の IndexedDB。

| ファイル | 役割 |
|---|---|
| `index.html`, `css/industry.css`, `css/app.css` | 画面。Industry のトークン(ブループリント調、角丸0)。ダークは端末の設定に従う |
| `js/core.js` | 純粋な計算(時間軸・目盛り・カード配置・関係線・入力検証・AI結果の反映)。`node --test` で確かめる |
| `js/app.js` | 描画と操作 |
| `js/text.js` | 画面の文言 |
| `js/seed.js` | 初期データ(科学技術史43件・関係27件) |
| `js/db.js` | IndexedDB(cats, events, links, ai, meta) |
| `js/sync.js`, `hub/` | 自分のスプレッドシート+Apps Script を「年表ハブ」にした端末間同期と、外部から出来事・因果関係を登録するAPI(別のAPIキーを `?key=` で渡す)。手順は [hub/README.md](hub/README.md) |
| `js/gemini.js` | Gemini API を端末から自分のキーで直接呼ぶ(押したときだけ) |
| `js/backup.js` | JSONで書き出し/読み込み(共有シート→iCloud Drive) |
| `sw.js` | オフライン用。ネット優先→キャッシュ |
| `vendor/fonts/` | Barlow / Barlow Condensed(SIL OFL)を同梱。日本語は端末の書体 |

## 出すときの決まり

- 出すたびに `sw.js` の `VERSION` を上げる。ファイルを足したら `SHELL` にも足す。
- `node --test tests/*.test.mjs`(または `npm test`)を通してから push する。
- ローカルで見る: `python3 -m http.server 8765` → http://localhost:8765/

## デザインからの変更点

- AIは「サーバー側から呼ぶ」推奨に対し、自分専用・費用0円の方針で Gemini を端末から自分のキーで呼ぶ(キーは端末の外に出さない)。
- 本番化で検討とされていた項目のうち、出来事の編集(カテゴリ変更を含む)、削除の「元に戻す」、端末間同期、書き出し/読み込み、タッチのピンチズームを入れた。
- 入力欄の文字は16px(iOSは16px未満の入力欄で画面を勝手に拡大するため)。
- 設定(AIキー・同期・バックアップ)は、左上の「年表」を押して開く。
- 年の上限は今年(固定の2026年ではなく)。
